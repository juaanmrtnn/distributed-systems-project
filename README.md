## Getting Started

To run a local copy:

### Prerequisites

You need a C compiler that supports OpenMP (like 'gcc') and an MPI implementation installed on your system (OpenMPI/MPICH).

* Ubuntu/Debian:
  ```bash
  sudo apt-get install openmpi-bin openmpi-doc libopenmpi-dev
  ```
